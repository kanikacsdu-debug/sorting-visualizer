# 📊 Sorting Visualizer

An interactive web application that demonstrates how popular sorting algorithms work through animated visualizations. Users can generate random arrays, choose a sorting algorithm, adjust the array size, and control the animation speed to better understand the sorting process.

## 🚀 Live Demo

 https://kanikacsdu-debug.github.io/sorting-visualizer/


## ✨ Features

* 🎲 Generate a random array
* 📈 Visualize sorting step by step
* ⚡ Adjustable visualization speed
* 📏 Adjustable array size
* 🧮 Multiple sorting algorithms

  * Bubble Sort
  * Selection Sort
  * Insertion Sort
  * Merge Sort
  * Quick Sort
* 💻 Clean and responsive user interface

## 📖 Sorting Algorithms Included

| Algorithm      | Average Time Complexity | Worst Time Complexity | Space Complexity |
| -------------- | ----------------------- | --------------------- | ---------------- |
| Bubble Sort    | O(n²)                   | O(n²)                 | O(1)             |
| Selection Sort | O(n²)                   | O(n²)                 | O(1)             |
| Insertion Sort | O(n²)                   | O(n²)                 | O(1)             |
| Merge Sort     | O(n log n)              | O(n log n)            | O(n)             |
| Quick Sort     | O(n log n)              | O(n²)                 | O(log n)         |
