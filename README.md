# sorting-visualizer
A simple and interactive web application that visualizes how different sorting algorithms work. Users can generate random arrays, choose a sorting algorithm, adjust the array size and visualization speed, and watch the sorting process step by step.

This project was built as my first JavaScript project to strengthen my understanding of DOM manipulation, asynchronous programming, and algorithm visualization.

Features
- Generate a random array
- Visualize sorting animations
- Multiple sorting algorithms:
    - Bubble Sort
    - Selection Sort
    - Insertion Sort
    - Merge Sort
    - Quick Sort
- Adjustable array size
- Adjustable animation speed
- Responsive user interface

Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)


Learning Outcomes
- DOM manipulation
- Event handling in JavaScript
- Working with asynchronous functions (async/await)
- CSS animations and transitions
- Implementation of classic sorting algorithms
- Creating interactive user interfaces
